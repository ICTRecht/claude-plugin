# ICTRecht MCP — Kennisbanken voor AI

Dit is de officiële repository voor ICTRecht MCP-servers en Claude-plugins. Elke map bevat een juridisch domein met een eigen server en plugin.

## Structuur

```
ictrecht-mcp/
└── privacy/          ← Privacy, AVG en gegevensbescherming
    ├── README.md     ← Installatie-instructies
    ├── main.py       ← MCP-server (Horizon)
    └── ictrecht-privacy/   ← Claude plugin
```

## Domeinen

| Map | Domein | Status |
|---|---|---|
| `privacy/` | Privacy, AVG, gegevensbescherming | ✅ Beschikbaar |
| `arbeidsrecht/` | Arbeidsovereenkomsten, ontslag | 🔜 Binnenkort |
| `ondernemingsrecht/` | Ondernemingsrecht, contracten | 🔜 Binnenkort |

## Snel aan de slag

Ga naar de map van het gewenste domein en volg de `README.md` daar.

**Privacy plugin installeren → [privacy/README.md](privacy/README.md)**
